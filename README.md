# Trading Simulator (Торговый симулятор на истории Т-Инвестиций)

Профессиональный веб-симулятор торговли на исторических данных с интерфейсом в стиле TradingView / OpenAlgo и интеграцией с API Т-Инвестиций.

## 🚀 Основные возможности

- **Торговля на истории (Bar Replay):**
  - Воспроизведение исторических баров с настраиваемой скоростью (0.5x, 1x, 2x, 4x, 10x).
  - Управление воспроизведением: пауза, шаг вперед, шаг назад, перемотка ползунком.
  - Бесшовный упреждающий предзагрузчик (prefetching) свечей без задержек и подвисаний.
  - Быстрый переход к любой исторической точке или дате.

- **Полноценный торговый функционал (Paper Trading):**
  - Поддержка рыночных (Market), лимитных (Limit) и стоп-заявок (Stop).
  - Торговля прямо с графика (Order Placement & Management).
  - Stop Loss и Take Profit с автоматическим трекингом и исполнением.
  - Корректная логика неттинга (Netting): частичное и полное закрытие позиций встречными ордерами, усреднение цены входа при доборе объема в ту же сторону.
  - Мгновенные кнопки быстрого закрытия позиций и отмены заявок.

- **Интерактивный график TradingView / OpenAlgo:**
  - Полноценная поддержка таймфреймов: `1м`, `5м`, `15м`, `1ч`, `4ч`, `1Д`, `1Н` с синхронизацией истории.
  - Полный набор инструментов технического анализа с оригинальными векторными SVG-иконками TradingView:
    - Трендовые линии, горизонтальные уровни и лучи, параллельные каналы, сетка Фибоначчи.
    - Разметка длинных и коротких позиций с расчетом риск/прибыль (R:R).
    - Прямоугольники, ценовые диапазоны (линейка), кисть, текст, магнит к ценам OHLC.
  - Технические индикаторы: SMA, EMA, Bollinger Bands, RSI, MACD, Volume.

- **Синхронизация с рынком:**
  - Загрузка реальных исторических данных акций и инструментов через официальный REST API Т-Инвестиций.
  - Автоматический расчет комиссии, нереализованного PnL, эквити и винрейта.

## 🛠️ Стек технологий

- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3 (TradingView Dark Theme), Vanilla JavaScript
- **Графическое ядро:** TradingView Lightweight Charts + OpenAlgo Charts
- **Источник данных:** Т-Инвестиции Open API (Tinkoff Invest API v2)

## 📦 Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd trading_simulator
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Настройте конфигурацию:
   - Скопируйте `config.example.json` в `config.json`:
     ```bash
     cp config.example.json config.json
     ```
   - Укажите ваш токен Т-Инвестиций в поле `tinkoffToken` (токен можно получить в личном кабинете Т-Банка с правами "только чтение").

4. Запустите сервер:
   ```bash
   npm start
   ```
   или запустите `start.bat`.

5. Откройте в браузере:
   ```
   http://localhost:3000
   ```
